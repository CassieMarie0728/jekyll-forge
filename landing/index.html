Three steps. No origin story.

  1. Connect your repo

    Sign in with GitHub, connect repository access, and choose the repository and branch Forge should work with.

  2. Write and recover

    Edit Markdown and front matter with a live preview. Recovery stays on this browser; Save keeps a draft in Forge.

  3. Review and publish

    Check the destination and diff. Commit to GitHub, create a branch or pull request, or schedule a new post.

Read the fine print. It has jokes.

Do I need a paid AI key?

No. AI is optional. Free provider options are available; optional Mistral billing follows your account. You bring your own key. Forge never switches providers automatically. Your wallet gets a vote.

Where do my drafts live?

Recovery copies live in this browser and can be restored or downloaded. Save stores the draft in Forge’s database. Publishing writes to your selected GitHub repository. Clearing browser data can remove recovery copies—save or download work you need to keep.

Will it install every Jekyll theme?

Forge can edit theme and plugin configuration. Custom themes may need extra dependencies or setup. It is a writing tool, not a tiny wizard living inside your Gemfile.

Does my laptop need to stay on?

No. The hosted app runs on Cloudflare. Scheduled jobs run on the server at roughly five-minute intervals, so a backlog can delay publication. Hosting and AI provider quotas still apply.

Where’s the ridiculously detailed documentation?

The Mintlify field manual is being prepared. Until then, the current setup guide covers hosting, storage, and known limitations. No button to an imaginary docs site. We have standards. Occasionally.
